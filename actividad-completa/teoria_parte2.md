# Parte 3: Búsqueda de datasets reales (конспект)

> Отдельная часть работы, не связана с Parte 2 (синтетический «грязный» датасет).
> Рекомендуемая папка в репозитории: `parte-3-datasets-reales/` (`teoria.md` + `practica.ipynb`).

## 1. Цель

Найти реальные датасеты, на которых можно применять методы предобработки данных: чистка, пропуски, выбросы, кодирование, дисбаланс классов, временные ряды, большие данные.

## 2. Каталог датасетов по группам

### 2.1. Datos tabulares complejos y Feature Engineering (табличные данные и создание признаков)

| Датасет | Описание | Основные задачи |
|---|---|---|
| Online Retail (UCI / Kaggle) | транзакции интернет-торговли в Великобритании, более 500 000 записей | отмена заказов (отрицательные количества), пропуски в ID клиента, разбор дат и времени, выбросы в цене, RFM-анализ |
| House Prices: Advanced Regression Techniques (Kaggle) | 79 признаков о домах в Эймсе (Айова) | условные пропуски (нет гаража, бассейна), порядковое и номинальное кодирование (One-Hot, Target Encoding), нелинейные преобразования (Log, Yeo-Johnson) для скошенной цены |
| Adult / Census Income (UCI) | данные переписи США: превышает ли годовой доход 50 000 $ | разнородные категории, лишние пробелы, редкие категории, нормализация числовых шкал |

### 2.2. Desbalanceo severo y detección de anomalías (сильный дисбаланс и аномалии)

| Датасет | Описание | Основные задачи |
|---|---|---|
| Credit Card Fraud Detection (Kaggle) | 284 807 транзакций, мошеннических 0,172 % | подбор порога решения, SMOTE только на train, оценка по PR-AUC, поиск аномалий без учителя (Isolation Forest, DBSCAN) |
| IEEE-CIS Fraud Detection (Kaggle) | большой набор онлайн-транзакций от Vesta Corporation | большой объём, выравнивание временных меток, много пропусков, сложные связи между анонимными признаками |

### 2.3. Series temporales y datos secuenciales (временные ряды)

| Датасет | Описание | Основные задачи |
|---|---|---|
| Store Sales: Time Series Forecasting (Kaggle / Corporación Favorita) | ежедневные продажи сети супермаркетов | лаги, скользящие окна, внешние данные (праздники, акции, цена нефти), выравнивание календарей без утечки данных |
| Air Quality / Beijing PM2.5 (UCI) | качество воздуха и погода по часам за несколько лет | заполнение пропусков в последовательностях (линейная интерполяция, сплайны, forward-fill), ресемплинг, сезонность |

### 2.4. Big Data y procesamiento distribuido (большие данные)

| Датасет | Описание | Основные задачи |
|---|---|---|
| NYC Yellow Taxi Trip Data | сотни миллионов поездок такси Нью-Йорка с координатами, временем, тарифами, чаевыми | оптимизация памяти, расстояния по формуле Haversine, чистка ошибочных поездок и координат вне города, распределённая обработка |
| AWS Open Data / Google Cloud Public Datasets (GitHub Activity, NOAA Historical Weather) | облачные хранилища масштаба терабайт | оптимизированные SQL/BigQuery-запросы, партиционирование, масштабируемый ETL |

## 4. Термины (Español → Русский)

| Español | Русский |
|---|---|
| Alta cardinalidad | большое число уникальных значений в категории |
| Ingeniería de características (Feature Engineering) | создание новых признаков |
| Codificación por objetivo (Target Encoding) | кодирование категории по среднему значению таргета |
| Análisis RFM (Recency, Frequency, Monetary) | анализ клиентов по давности, частоте и сумме покупок |
| Detección de anomalías | поиск аномалий |
| Rezago (Lag) | значение признака из предыдущего периода |
| Ventana móvil (Rolling Window) | скользящее окно |
| Interpolación | интерполяция (заполнение пропусков по соседним значениям) |
| Estacionalidad | сезонность |
| Remuestreo (Resampling) | изменение частоты данных или баланса классов |
| Procesamiento distribuido | распределённая обработка |
| Sobremuestreo (SMOTE, ADASYN) | увеличение выборки редкого класса |
| Aprendizaje sensible al costo (Cost-Sensitive) | обучение с учётом цены ошибок |
